# Contributing to WoW_Bounty

Thank you for considering contributing to **WoW_Bounty**! We welcome bug reports, feature requests, pull requests, and feedback.

## 🚀 Getting Started

1. **Fork the Repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/WoW_Bounty.git
   cd WoW_Bounty
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Start Development Server**:
   ```bash
   npm run dev
   ```

## 🛠️ Code Conventions

- **Framework**: React 19 + Vite + TailwindCSS v4 + Framer Motion
- **Icons**: Lucide React
- **Linting**: Oxlint (`npm run lint`)
- Make sure to format your code cleanly and verify builds before submitting a Pull Request:
  ```bash
  npm run lint
  npm run build
  ```

## ⚔️ Submitting Pull Requests

1. Create a descriptive branch: `git checkout -b feature/awesome-bounty-feature`
2. Commit your changes with clear messages.
3. Push to your branch and open a Pull Request against `main`.
